# 条材排料台

本地单文件应用，整数毫米、同长条材、最多18件的精确子集装箱规划。每件固定预留一条锯缝（含每根最后一件），每根两端各扣修边。无设备控制、无服务端输入上传。

构建：node build.cjs
测试：node --test tests/core.test.cjs
本地：python3 -m http.server 8818 --bind 127.0.0.1

默认示例为虚构数据。最少根数不等于最少刀数；不处理夹持余量、材料缺陷、纹理、斜切与二维排版。实际施工前请另行核对。

AppCore.solve输出精确计划、输入顺序Next Fit对照、长度守恒、余料与利用率。O(n·2^n)。不依赖网络库。
